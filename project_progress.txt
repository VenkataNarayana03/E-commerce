PHASE 5: SHOPPING CART MODULE
=============================
Goal
----
Enable customers to add products to cart, view cart items, modify quantities, remove items, clear cart, and calculate real-time subtotals and totals.

Backend Changes
---------------
- Schemas (`backend/app/schemas/cart.py`):
  - `CartItemCreate`, `CartItemUpdate`, `CartItemRead`, `CartResponse`.
- Service (`backend/app/services/cart_service.py`):
  - Added stock checking, duplicate item prevention, item quantity update, item deletion, cart clearing, and price subtotal calculations.
- Routes (`backend/app/routes/cart.py`):
  - `GET /api/cart`
  - `POST /api/cart`
  - `PUT /api/cart/{cart_item_id}`
  - `DELETE /api/cart/{cart_item_id}`
  - `DELETE /api/cart` (clear cart)

Frontend Changes
----------------
- API Service (`frontend/src/services/cartService.js`): Axios integration for cart endpoints.
- Context (`frontend/src/context/CartContext.jsx`): Real-time backend synchronization for logged-in users, guest state fallback with login prompt for order placement, and Toastify notifications.
- Cart Page (`frontend/src/pages/Cart/Cart.jsx`): Item thumbnails, inline quantity modifier (+ / -) controls, delete buttons, order summary sidebar, free shipping calculator, and checkout routing.
- Product Details Page (`frontend/src/pages/ProductDetails/ProductDetails.jsx`): Quantity selector (1 to stock) and instant cart actions.
- Navbar (`frontend/src/components/Navbar/Navbar.jsx`): Real-time cart item counter badge.


PHASE 6: CHECKOUT & ORDERS MODULE
=================================
Goal
----
Enable customers to place orders from their cart items, store shipping addresses, select payment methods, automatically reduce product stock, clear the cart, and view order history.

Backend Changes
---------------
- Schemas (`backend/app/schemas/order.py`):
  - `OrderCreate`, `OrderItemRead`, `OrderRead`, `OrderListResponse`.
- Service (`backend/app/services/order_service.py`):
  - Generates unique order number (e.g. `ORD-20260730055005-894F0F`).
  - Validates cart contents and product stock levels.
  - Creates `Order` and `OrderItem` records.
  - **Stock Deduction**: Automatically subtracts purchased quantity from `product.stock_quantity`.
  - **Cart Clearing**: Flushes user cart items upon order placement.
  - Calculates subtotal, shipping fee, and grand total amount.
  - Service functions for fetching user orders and single order details.
- Routes (`backend/app/routes/orders.py`):
  - `POST /api/orders`
  - `GET /api/orders`
  - `GET /api/orders/{order_id}`

Frontend Changes
----------------
- API Service (`frontend/src/services/orderService.js`): Axios integration for placing and fetching orders.
- Checkout Page (`frontend/src/pages/Checkout/Checkout.jsx`):
  - Full Address Form (Name, Phone, Address Line 1 & 2, City, State, Postal Code, Country).
  - Payment Method Selection (Cash On Delivery, UPI, Credit/Debit Card).
  - Order Items Summary sidebar with item previews, prices, shipping fee, and total.
  - Order Confirmation screen displaying order ID, status, and shipping address after successful checkout.
- Orders Page (`frontend/src/pages/Orders/Orders.jsx`):
  - List of past orders with status badges (`CONFIRMED`, `PENDING`, `SHIPPED`, `DELIVERED`).
  - Order items breakdown table, payment method, shipping details, and total paid.
